المزامنة التلقائية مع Git

اربطي الدفتر بمستودع على GitHub — كل تغيير (إضافة/حذف) يُرفع تلقائيًا كنسخة كاملة من الملف بعد ثوانٍ من التوقف عن الكتابة. تقدرين أيضًا ترفعين أو تجلبين آخر نسخة يدويًا.

⚠️ التوكن يُحفظ في ذاكرة هذا المتصفح على جهازك فقط (مو داخل الملف نفسه) — عشان GitHub يمنع تلقائيًا رفع أي ملف فيه توكن ظاهر بداخله. يعني ما راح يُطلب منك إدخاله كل مرة على نفس الجهاز والمتصفح، لكن إذا فتحتِ الملف من جهاز أو متصفح ثاني بتحتاجين تكتبينه فيه مرة وحدة. يفضّل إنشاء توكن بصلاحية الكتابة على هذا المستودع فقط (Fine-grained token).
