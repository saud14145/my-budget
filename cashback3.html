حدود الاسترداد الشهرية (الفرنسي) — الشهر الحالي

يُطبَّق الحد تلقائيًا أول ما تصل عمليات فئة معينة لسقفها الشهري — أي عمليات إضافية بنفس الفئة تُحسب بدون استرداد إضافي لباقي الشهر.

ملاحظات

تتحدث هذه اللوحة تلقائيًا فور تحليل رسائل جديدة من تبويب "لصق الرسائل". جميع البيانات محفوظة محليًا على متصفح هذا الجهاز فقط (localStorage) — استخدم زر "نسخة احتياطية" في تبويب الإعدادات بشكل دوري لتصدير نسخة JSON، خصوصًا قبل مسح بيانات المتصفح أو تغيير الجهاز.

محاكاة قبل الشراء

أدخل التاجر والمبلغ، وشوف أي بطاقة تعطيك أعلى استرداد فعلي الآن (بعد اعتبار المتبقي من الحد الشهري لكل بطاقة).

محاكاة نهاية دورة الكشف

أدخل مصروف إضافي متوقع لكل فئة حتى نهاية الدورة، وشوف الاسترداد المتوقع وهل بتوصل لحد أي فئة.

التحليل الذكي

تحليل مبني على عمليات الفرنسي المحسوبة تلقائيًا (لأن لها فئة واضحة قابلة للمقارنة الفورية). عمليات الأهلي تُقارن تقديريًا فقط لأن استردادها الفعلي يعتمد على حدود متغيرة بمرور الشهر.

تقييم البطاقات

مقارنة سيناريوهات

استردادك الفعلي حتى الآن، مقابل لو كنت تستخدم كل مرة أفضل بطاقة ممكنة، ومقابل لو استخدمت بطاقة واحدة بس لكل عملياتك.

اسأل عن بياناتك

أمثلة: "كم باقي لي في حد الوقود؟" / "كم استردادي هذا الشهر؟" / "كم صرفت في ARAMCO؟" / "ما أفضل بطاقة لـ MILA MART؟" / "كم بقي على نهاية الدورة؟"

لصق رسائل البنك

الصق أي عدد من الرسائل دفعة واحدة، رسالة تلو الأخرى كما وصلتك بالضبط. لا حاجة لفصلها بأسطر فارغة — النظام يكتشف بداية كل رسالة تلقائيًا.

لو عدّلت فئة، نسبة، حد شهري، أو دورة كشف بعد ما حلّلت رسائل — ما تحتاج تعيد لصقها؛ زر "إعادة تحليل كل شيء" بتبويب الإعدادات يعيد حساب كل العمليات الموجودة بالإعدادات الجديدة مباشرة.

النسخ الاحتياطي والبيانات

بياناتك محفوظة محليًا على هذا المتصفح فقط. صدّر نسخة احتياطية بشكل دوري أو قبل تغيير الجهاز.

المزامنة التلقائية مع GitHub

تحفظ البيانات تلقائيًا كـ commit في مستودعك على GitHub — بدون تحميل أو رفع يدوي، وكل حفظة مسجّلة في سجل التغييرات (Commits) بالمستودع. يعمل هذا أيضًا كنسخة سحابية تظهر على أي جهاز تفتح منه نفس الصفحة.

لإنشاء Token: من إعدادات GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → اختر هذا الريبو فقط → صلاحية Contents: Read and write. الـ Token يُحفظ فقط على هذا الجهاز ولا يُرسل لأي مكان غير GitHub.

عمليات تحتاج مراجعة (فروقات محتملة)

عمليات أهلي احتُمل فيها الوصول للحد الشهري، وعمليات فرنسي طُبِّق عليها تقليص بسبب الحد الشهري.

سجل التعديلات وإعادة التحليل

كل تعديل على المحلات، البطاقات، الفئات، أو النسب — وكل عملية "إعادة تحليل" — تُسجَّل هنا تلقائيًا.

سجل الأخطاء

رسائل ما قدر النظام يفهمها، أو عمليات استُخرج منها مبلغ/تاريخ ناقص. راجعها لو حسّيت الأرقام ناقصة عمليات.

أرشيف الرسائل الخام

كل رسالة تم لصقها، كما وصلت بالضبط، للرجوع إليها عند مراجعة أي خطأ في التحليل.
